# devops-lab2
Ćwiczenie z podstaw Git i GitHub
Nazwa: DevObs Lab 2

 Wykorzystane narzędzia
- Git
- GitHub
- terminal

Instrukcja uruchomienia / pracy
1. Utworzenie repozytorium na GitHub.
2. Sklonowanie repozytorium: `git clone <adres-repo>`
3. Utworzenie pliku i dodanie zmian: `git add .`
4. Zapisanie zmian: `git commit -m "opis zmiany"`
5. Wysłanie zmian na GitHub: `git push`
6. Praca na gałęziach: `git checkout -b nowa-galaz`
7. Scalanie zmian: `git merge`

Git-historia zmin GitHub- Pull Request i code review
